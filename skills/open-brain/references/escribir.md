# Route card: escribir

> **This is a routing card, not the skill.** The full, current rules live in the `open-brain-escribir` skill. Once you have routed here, load `open-brain-escribir` and follow its `SKILL.md` (and the references it names) end to end. Do not execute from this card.

## Route here when

- I want to write / I have an idea / save this / write about X / islands session / work on manuscript M[N] / this extends [[note]].

## What the skill does

Saves what you write or paste, verbatim, as an *island* (orphaned if no manuscript is open) and returns ONE question that provokes the next island. The model never drafts prose for you. Grounding is limited to at most one note, the one that contradicts you, and only after saving. Manuscripts emerge later, when three or more islands cluster and you write the core idea.

## Route elsewhere when

- Pure lookup with no intent to write: **retrieve**.

## Usual next step

- **ingest**, if a new insight was saved.
- **autolink** runs silently afterwards.
